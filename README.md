# Personal Portfolio Website

A responsive personal portfolio website built to showcase my skills, education, projects, resume, and contact information.

This portfolio is designed as a clean personal-brand website with a light minimal layout, animated transitions, project cards, and a working contact form backend. The contact form saves messages to a MySQL database and sends an email notification using PHPMailer.

## About the Project

This portfolio represents my journey as a Computer Science student and beginner full-stack web developer. It includes my personal introduction, education, selected projects, technical skills, resume download, social links, and a contact section.

The goal of this project is to create a professional online presence that I can share with recruiters, internship providers, and clients.

## Features

- Responsive personal portfolio design
- Smooth scroll navigation
- Animated section reveal on scroll
- Hero section with profile image and social links
- About Me section
- Experience and Education timeline
- Selected projects section
- Resume download option
- Contact information cards
- Contact form with PHP backend
- Messages saved to MySQL database
- Email notification using PHPMailer
- Clean folder structure
